# SoundCloud Downloader — Windows

## Что это
Небольшое GUI-приложение для Windows: вставляете URL публичного профиля/плейлиста SoundCloud, выбираете папку и начинаете загрузку доступных треков.

Программа не обходит приватность, платный доступ или ограничения правообладателя. Загружаются только записи, которые yt-dlp может получить законным и технически доступным способом.

## Получить готовый EXE через GitHub Actions
В этой среде нельзя надёжно собрать и проверить нативный Windows `.exe`: сборка выполняется на Linux. В проект добавлен workflow, который соберёт EXE на Windows runner GitHub.

1. Создайте новый пустой репозиторий на https://github.com/new.
2. Распакуйте архив и загрузите в репозиторий все файлы и папку `.github`.
3. Откройте вкладку **Actions** репозитория.
4. Выберите **Build Windows EXE** и нажмите **Run workflow** (или дождитесь сборки после push в `main`).
5. После успешной сборки откройте завершённый запуск workflow. Внизу страницы в разделе **Artifacts** скачайте `SoundCloudDownloader-Windows`.
6. Распакуйте ZIP артефакта. Внутри будет `SoundCloudDownloader.exe`.

## Важное про MP3 и обложки
Для конвертации в MP3 и встраивания обложек требуется FFmpeg. Без FFmpeg снимите соответствующие галочки в приложении — тогда можно скачивать исходный аудиоформат, если он доступен.

## Локальный запуск из исходников (необязательно)
```powershell
py -m pip install -r requirements.txt
py soundcloud_downloader.py
```
